# SG Flowers — storefront demo

GitHub-ready static e-commerce demo for SG Flowers Singapore. Open `index.html` or run `python3 -m http.server 8000`.

Includes product catalogue based on supplied SG Flowers menus, filtering, cart, delivery scheduling and WhatsApp order handoff. **No payment processing or order backend** is active. The product photos and orchid logo were extracted from the supplied SG Flowers PDF menus. The customized garland PDF did not arrive.

To publish: upload these files to a GitHub repository and enable Pages from its root. A public web app reveals delivered frontend code to visitors. For a private client preview, use private-access hosting.

Before launch: reconfirm menu prices and stock, verify delivery zones, implement a secure backend and HitPay hosted checkout with verified webhooks, and create an admin system.
